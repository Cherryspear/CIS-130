Layout Problems

One problem was the content and sidebar not lining up right. Another problem was the CSS not matching the HTML correctly, so some of the layout rules did not work.

Breakpoint

I used 768 pixels because it lets the page change depending on the screen size. Smaller screens stack the content, and bigger screens put it side by side.

Navigation

I changed the menu so it goes up and down on small screens and side to side on bigger screens. I also added a dropdown for the About link.

Container Query

The cards stack on top of each other when there is less space. When the card area gets wider, they can sit next to each other instead.
